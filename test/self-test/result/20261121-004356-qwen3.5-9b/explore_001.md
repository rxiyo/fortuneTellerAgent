## 紫微斗数模块概览

| 模块 | 功能说明 |
|------|----------|
| **chart** | 紫微斗数排盘：照《紫微斗数全书》卷二「安身命例」诸诀，把生辰排成十二宫命盘 |

| **hepan** | 合盘：两张紫微命盘之间的结构化指标 |
| **xianyun** | 运限论断：照《紫微斗数全书》卷三限运诸论，判一张盘某一时刻的大限、小限、流年 |
| **yunxian** | 运限：大限、小限、流年、流月、流日、流时 |

## 排盘所需信息（ziwei.chart.build_chart）

要排紫微命盘，需要提供以下核心参数：

### 必需参数
1. **dt** - 出生时间（datetime格式）
   - 需包含日期和时间，例如 `2000-01-01T12:00:00+08:00`
   - 按出生地钟表时间和实际时区传入

2. **gender** - 性别
   - `0` 表示男
   - `1` 表示女

### 可选参数（有默认值）
3. **leap** - 闰月处理：`'next'` / `'half'` / `'same'`（默认 `'next'`）
4. **late_zi** - 子时处理：`'next'` / `'same'`（默认 `'next'`）
5. **kuiyue_bingding** - 天魁天钺的丙丁位（默认 `'酉'`）
6. **changsheng** - 长生诀选择：`'book'` / `'yinyang'`（默认 `'book'`）
7. **tongxing** - 同星设置（默认 `True`）
8. **daxian_start** - 大限起始：`'ming'` / `'next'`（默认 `'ming'`）
9. **sihua_ren** - 四化人选择：`'天府'` / `'左辅'`（默认 `'天府'`）
10. **miaowang** - 庙旺判断：`'juan3'` / `'juan2'`（默认 `'juan3'`）
